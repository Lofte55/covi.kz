## Анимации (assets/app.js)

- **Scroll reveal** — `.reveal` (одиночные блоки), `.reveal-group` (стаггер по детям, до 6 элементов через `nth-child`), `.img-reveal` (масштаб-реveal для фото). IntersectionObserver, `threshold: .12`
- **Count-up чисел** — `data-count="28" data-suffix=" м²"` на элементе → анимированный подсчёт при появлении во вьюпорте (cubic ease-out, 1100ms)
- **Параллакс иллюстраций** — `data-parallax="18"` на изображении, лёгкий сдвиг по скроллу
- **Аккордеон процесса** (`.acc-item` / `.acc-head` / `.acc-body`) — первый пункт открыт по умолчанию; при переключении шага меняется фото в `.proc-visual img` через `data-image` / `data-image-alt` на `.acc-item` (класс `.imgfade` даёт короткую анимацию смены)
- **FAQ-аккордеон** (`.faq-item` / `.faq-q` / `.faq-a`, обёрнуты в `.faq-list` — JS ищет ближайший `.faq-list`, иначе фолбэк на весь документ)
- **Модальное окно заявки** (`#lead-modal` / `[data-modal-open]` / `[data-modal-close]`) — на каждой странице есть копия модалки перед `</body>`; открывается по клику на любую кнопку "Оставить заявку"
- **Телефон:** маска `+7 XXX XXX XX XX` на всех `input[type=tel]`, валидация по 11 цифрам
- **Email:** валидация по regex на `input[type=email]`
- **Кастомный select** (`.csel`) — оборачивает нативный `<select>`, свой список вместо системного, стрелка вращается при открытии
- **Чекбокс согласия** (`input[data-consent]` в `.consent-row`) — обязателен для отправки формы, подсвечивается красным при попытке отправить без галочки
- **Дропдаун "Услуги" в хедере** (`.has-drop` / `.drop-trigger` / `.drop-panel`) — клик-тоггл, закрывается по клику вне/Esc; на мобильных (`<940px`) превращается в статичный раскрывающийся список внутри мобильного меню
- Везде уважается `prefers-reduced-motion: reduce` (см. низ styles.css)

## Мобильная версия (v4)

- **Хедер:** на `≤940px` — только лого + бургер. Всё остальное (телефон, соцсети, город, CTA) переезжает внутрь выпадающего мобильного меню (`.nav-mobile-extra`, лежит в конце `.nav-links`)
- **Бургер:** был баг — инлайн `onclick` и JS-обработчик оба дёргали `classList.toggle('open')` на одном и том же элементе (`.nav-links` имеет `id="nav"`), два toggle гасили друг друга. Убрал инлайн-обработчик, оставил только JS в app.js
- **Hero:** на мобильных текст/бейджи/статистика центрируются, `.hero-stats` — грид 2×2 с последней ячейкой на всю ширину
- **Блок "28 стран":** `.trust-head` в столбец, `.th-num` — маленькая пилюля вместо гигантской цифры, `.trust-grid` 2 колонки с последней ячейкой на всю ширину
- **Процесс:** на мобильных общее фото сбоку (`.proc-visual`) скрыто, вместо него — маленькое фото внутри каждой карточки шага (`.acc-card-img`, статичный `<img>`, без JS)
- **Отзывы + отрасли:** `.tgrid` / `.mini-tgrid` на `≤768px` превращаются в горизонтальную бесконечную карусель — JS клонирует карточки (`.tcard-clone`, скрыты на десктопе), автопрокрутка `setInterval` + пауза при touch/mouse. **Важно:** `scroll-snap-type` ломает программную прокрутку (браузер мгновенно откатывает `scrollLeft` к ближайшей точке снапа) — специально не используется
- **Кнопки:** `.route-btn` и `.cta-actions .btn` на `≤600px` — на всю ширину, друг под другом

## Как вносить правки

- **Правка текста/контента одной страницы** → открыть соответствующий `.html`, искать по ключевым словам (заголовки секций на русском)
- **Правка стиля/цвета/отступов глобально** → `assets/styles.css`, переменные в `:root`
- **Правка анимации/интерактива** → `assets/app.js`
- **Правка меню/шапки/футера/модалки** → повторить правку во всех 8 HTML-файлов (нет единого include); для массовой правки проще написать одноразовый Python-скрипт с regex по `<header class="nav">...</header>` / `<footer class="footer">...</footer>`
- **Добавление новой страницы** → скопировать структуру любой из услуговых страниц (например `svh.html`), обновить title/description/canonical/H1/контент, добавить ссылку в nav всех страниц + в `sitemap.xml`
- **Локальная проверка** → `preview_start name="sovi"` (см. `../.claude/launch.json`) → http://localhost:3134/
