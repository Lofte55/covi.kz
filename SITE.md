## Анимации (assets/app.js)

- **Scroll reveal** — `.reveal` (одиночные блоки), `.reveal-group` (стаггер по детям, до 6 элементов через `nth-child`), `.img-reveal` (масштаб-реveal для фото). IntersectionObserver, `threshold: .12`
- **Count-up чисел** — `data-count="28" data-suffix=" м²"` на элементе → анимированный подсчёт при появлении во вьюпорте (cubic ease-out, 1100ms)
- **Параллакс иллюстраций** — `data-parallax="18"` на изображении, лёгкий сдвиг по скроллу
- **Аккордеон процесса** (`.acc-item` / `.acc-head` / `.acc-body`) — первый пункт открыт по умолчанию
- **FAQ-аккордеон** (`.faq-item` / `.faq-q` / `.faq-a`)
- Везде уважается `prefers-reduced-motion: reduce` (см. низ styles.css)

## Как вносить правки

- **Правка текста/контента одной страницы** → открыть соответствующий `.html`, искать по ключевым словам (заголовки секций на русском)
- **Правка стиля/цвета/отступов глобально** → `assets/styles.css`, переменные в `:root`
- **Правка анимации/интерактива** → `assets/app.js`
- **Правка меню/шапки/футера** → повторить правку во всех 7 HTML-файлов (нет единого include)
- **Добавление новой страницы** → скопировать структуру любой из услуговых страниц (например `svh.html`), обновить title/description/canonical/H1/контент, добавить ссылку в nav всех страниц + в `sitemap.xml`
